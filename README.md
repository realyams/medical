L'objectif est de concevoir un système d'aide à la décision clinique (CDSS) multimodal. Contrairement aux approches textuelles classiques, ce projet vise à fine-tuner un modèle de vision-langage capable de corréler des données visuelles (radiographies, scanners) avec des données textuelles (historique patient, symptômes) pour générer un diagnostic différentiel et des recommandations d'investigation.
